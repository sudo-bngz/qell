# Keyboard shortcuts

On macOS, `Ctrl` in this list is `⌘` for the editor shortcuts — `⌘S`,
`⌘P`, `⌘⇧P` — and the same commands are in the native menu bar. Every
command is also in the palette (`Ctrl/⌘+Shift+P`), with its shortcut.

## General

| | |
|---|---|
| Command palette | `Ctrl+Shift+P` |
| Go to file | `Ctrl+P` |
| Go to line | `Ctrl+G` |
| Settings | `Ctrl+,` |
| Toggle sidebar | `Ctrl+B` |
| Explorer | `Ctrl+Shift+E` |
| Search in files | `Ctrl+Shift+F` |
| Source Control | `Ctrl+Shift+G` |
| Problems | `Ctrl+Shift+M` |
| Kubernetes cluster | `Ctrl+Shift+K` |
| AWS | `Ctrl+Shift+A` |
| Zoom in / out / reset | `Ctrl+=` / `Ctrl+-` / `Ctrl+0` |
| Quit | `Ctrl+Q` |

## Files and tabs

| | |
|---|---|
| New file | `Ctrl+N` |
| Open file / folder | `Ctrl+O` / `Ctrl+Alt+O` |
| Save / Save as | `Ctrl+S` / `Ctrl+Shift+S` |
| Close tab | `Ctrl+W` |
| Next / previous tab | `Ctrl+Tab` / `Ctrl+Shift+Tab` |
| Split editor | `Ctrl+\` |
| Focus left / right side | `Ctrl+1` / `Ctrl+2` |
| Markdown preview | `Ctrl+Alt+V` |

## Editing

| | |
|---|---|
| Undo / redo | `Ctrl+Z` / `Ctrl+Y` |
| Select all | `Ctrl+A` |
| Add next occurrence | `Ctrl+D` |
| Select all occurrences | `Ctrl+Shift+L` |
| Add cursor above / below | `Ctrl+Alt+↑` / `Ctrl+Alt+↓` (`⌥⌘↑` / `⌥⌘↓`) |
| Add or remove a cursor | `Alt`+click |
| Toggle comment | `Ctrl+/` |
| Format | `Shift+Alt+F` |
| Fold / unfold | `Ctrl+Alt+[` / `Ctrl+Alt+]` |
| Word wrap | `Alt+Z` |
| Find / replace | `Ctrl+F` / `Ctrl+H` (`⌥⌘F`) |
| Find next / previous | `F3` / `Shift+F3` |
| Replace in files | `Ctrl+Shift+H` |

## Code

| | |
|---|---|
| Trigger completion | `Ctrl+Space` |
| Parameter hints | `Ctrl+Shift+Space` |
| Go to definition | `F12`, `Ctrl`+click |
| Find all references | `Shift+F12` |
| Back / forward | `Alt+←` / `Alt+→` (`⌃-` / `⌃⇧-`) |
| Go to symbol in file | `Ctrl+Shift+O` |
| Rename symbol | `F2` |
| Quick fix | `Ctrl+.` |
| Run test at cursor | `Ctrl+Alt+T` |
| Run task | `Ctrl+Shift+B` |
| Git blame | `Ctrl+Alt+B` |

## Terminal

| | |
|---|---|
| Show / hide | `` Ctrl+` `` |
| New terminal | `` Ctrl+Shift+` ``, `⌘T` on macOS |
| Next / previous terminal | `Ctrl+PageDown` / `Ctrl+PageUp` |
| Copy | `Ctrl+Shift+C` (`⌘C`) with a selection |
| Paste | `Ctrl+Shift+V` (`⌘V`) |
